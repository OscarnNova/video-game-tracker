## Funcionalidades implementadas
- Backend REST (GET/POST/PUT/DELETE) + MongoDB Atlas
- Frontend social: perfil OscarnNova, biblioteca, filtros por status
- Portadas de juegos via RAWG API
- Fondo dinámico: 42 íconos pixel art flotantes con repulsión al mouse
- Bombas con mecha animada, explosión y lógica de cercanía al centro (8-16 seg de vida)
- Cursor custom leather glove (4 estados: normal/hand/clicking/grab)
- Favicon pixel art
- Card REDES SOCIALES (7 íconos SVG)
- TOP 3 géneros más jugados
- Paginación (5 juegos por página)
- 4 status: Jugando / Completado / Pendiente / Wishlist
- Edit/Delete por card (⠿ y ✕)
- Completado = irreversible, sin botón eliminar, estrellas editables
- No duplicados (modal elegante)
- Confirmación al eliminar (modal con Aceptar/Rechazar)
- Modal duplicado con z-index correcto (1100)
